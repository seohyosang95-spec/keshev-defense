# 케셰브 처음 설치 안내

처음 사용하는 사람은 이 문서만 따라 하세요. 기존 프로젝트 폴더를 지우거나 옮길 필요가 없습니다.

## 1. 먼저 준비할 것

- Windows PC
- Node.js 22~24 계열
- 수업 기준 권장 버전: Node.js 24.19.0

Node.js가 없다면 [공식 다운로드 페이지](https://nodejs.org/en/download)에서 설치한 뒤 PowerShell 창을 새로 엽니다. 별도 npm 패키지 설치는 필요하지 않습니다.

## 2. 설치 프로그램 실행

1. 같은 배포 폴더의 `KeshevSetup-버전.exe`를 실행합니다.
2. 설치 위치는 기본값을 사용해도 됩니다.
3. 설치가 끝나면 바탕화면 또는 시작 메뉴의 `케셰브` 바로가기를 엽니다.

이 설치는 사용자 단위 설치입니다. 설치가 보안 정책에 의해 차단되면 보호 기능을 끄지 말고 차단 메시지를 담당자에게 전달합니다.

## 3. 정상 실행 확인

브라우저가 `http://127.0.0.1:5189/`를 열면 다음을 확인합니다.

- `보호 현황` 화면이 보이는가
- `케셰브 실행 안내` 카드가 보이는가
- `내 PC 상태`에서 CPU·메모리·디스크 실측값과 시각이 보이는가
- `연결 없음`이 보여도 앱 서버가 실행된 것인지 구분했는가

`연결 없음`은 앱 서버 오류가 아니라 운영 계정·SDP 연결이 아직 준비되지 않은 상태일 수 있습니다.

## 4. 설치 묶음을 직접 실행하는 경우

설치 프로그램 대신 폴더를 받은 경우, 앱 폴더에서 PowerShell을 열고 실행합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\launch-keshev.ps1
```

## 5. 문제가 생기면

- 포트 5189가 사용 중이면 명령 끝에 `-Port 5190`을 붙이고 브라우저 주소도 `:5190`으로 바꿉니다.
- Node.js 오류, 포트 오류, 실행 창의 메시지 전체를 보관합니다.
- 방화벽·Defender·SmartScreen을 끄거나 인증서·토큰·API 키를 입력하지 않습니다.

앱을 실행한 뒤에는 화면 상단의 `케셰브 실행 안내`에서도 같은 순서를 다시 볼 수 있습니다.
